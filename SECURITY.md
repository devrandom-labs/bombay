# Security Policy

Security fixes target the latest released `0.x` line of Bombay.

Please do not report vulnerabilities through public issues or pull requests.
Use GitHub's private vulnerability reporting flow instead:

<https://github.com/devrandom-labs/bombay/security/advisories/new>

Include the affected version or commit, impact, and a minimal reproduction when
possible. Runtime isolation failures, unsafe resource growth, dependency
vulnerabilities, and panics reachable through public runtime inputs are in
scope. Application-specific policy errors outside this repository are not.
